클라이언트 관점

클라이언트에게 이렇게 설명하세요

개발사가 클라이언트를 설득할 때 활용할 수 있는 포인트입니다.

Point 01

유지보수 비용이 줄어듭니다

기존에는 홈페이지 내용 하나 바꾸려면 개발사에 연락하고 비용을 지불해야 했습니다. "텍스트 바꿔주세요", "이미지 교체해주세요" — 이제 직접 하실 수 있습니다.

  • 관리자 페이지에서 텍스트·이미지 직접 수정
  • 배너 교체, 마감 설정, 잔여 수량 관리
  • FAQ, 이벤트, 공지·게시글 직접 운영

Point 02

비용이 저렴하고 유연합니다

관리자 페이지를 별도로 개발하면 100만원 이상이 드는데, 디보는 연간 11만원대입니다.

  • 월 9,800원으로 관리자 페이지 기능 전체 이용
  • 약정 없음 — 필요할 때 구독, 언제든 해지 가능
  • 첫 달 무료 체험 (STARTER 플랜)
  • 코드 지식 없이 운영 가능

이용 흐름

세 단계로 구성됩니다

Step 01

프론트엔드 코드 준비

di-bo.me에서 원하는 UI 익스텐션을 선택해 코드를 무료로 복사하거나, 직접 작성한 프론트 코드에 디보 API를 연동합니다.

메인 — React / Vue / 일반 HTML 서브 — 아임웹 코드 위젯 익스텐션 코드 무료 제공
Step 02

클라이언트 회원가입 및 구독

클라이언트가 디보에 직접 회원가입하고 본인 카드로 구독 결제합니다. 프리랜서·개발사는 클라이언트 계정으로 접속해 관리 사이트 생성·연동·설정을 대신 진행합니다.

등록 즉시 대시보드 자동 생성 구독 사이트 내 익스텐션 무제한 연동
Step 03

관리자 페이지에서 운영

클라이언트가 관리자 페이지에서 데이터를 확인하고 콘텐츠를 수정합니다. 코드 지식 없이 운영 가능합니다.

제출 데이터 실시간 확인 콘텐츠 직접 수정 코드 수정 없음

FAQ

자주 묻는 질문

네. 아임웹 코드 위젯에 복사한 코드를 붙여넣으면 바로 적용됩니다. 관리 기능 연동 시 디보 구독이 필요합니다.
네. 관리자 페이지는 코드 지식 없이도 사용 가능하도록 설계되어 있습니다. 엑셀이나 구글 폼 수준으로 운영할 수 있습니다.
구독은 사이트 단위로 적용됩니다. 구독한 사이트 내에서는 익스텐션을 무제한 연동할 수 있지만, 다른 사이트에도 관리 기능을 사용하려면 해당 사이트를 별도로 구독해야 합니다.
네. 직접 작성한 프론트엔드 코드도 디보 API와 연동할 수 있습니다. 디보가 제공하는 API 호출 구조를 따르면 커스텀 UI에서도 동일하게 관리 기능을 사용할 수 있습니다.
무료 제공 코드는 비상업적 용도에 한해 허용되며, 상업적 이용은 사전 서면 동의가 필요합니다. 출처 표기(di-bo.me)는 필수입니다.
