# DIBO Popup Extension Series 디자인 및 기능 기획 문서

## 개요

DIBO Popup Series는
단순 기능형 팝업이 아닌,

* 인터랙션 경험
* 브랜드 감도
* 운영 효율
* 관리자 연동

까지 함께 고려한 팝업 시스템을 목표로 합니다.

각 팝업은 서로 다른 디자인 컨셉과 목적을 가지며,
서비스 성격에 맞는 UI/UX를 제공합니다.

---

## 개발 순서

팝업 시리즈를 개발할 때 아래 순서를 따릅니다.

1. **디자인 컨셉 확인** — 이 문서(add-popup.md)에서 해당 번호의 디자인 컨셉, 레이아웃 구조, UI 패턴을 확인합니다.
2. **API 및 개발 정책 확인** — `DIBO_API.md`에서 팝업 시리즈 개발에 필요한 Popup API 스펙과 공통 개발 정책(상단 주석 작성 규칙, 샘플 데이터 폴백 패턴, 토큰 변수명 등)을 확인합니다.
   - 폼 제출이 필요한 팝업은 Popup API(GET) + Edit API(POST)를 조합하여 개발합니다.
3. **명령어에 따라 해당 시리즈 개발** — 아래 개발 명령어 표의 시리즈 번호에 맞춰 `popup/` 폴더에 파일을 생성합니다.
4. **문서 진행 상황 업데이트** — 개발 완료 후 이 문서의 **개발 진행 상황**에 체크 및 완료 날짜를 기록합니다.

---

## 레이아웃 설계 원칙

각 팝업은 **레이아웃 구조 자체를 다르게** 설계합니다.
색상·색조만 바꾸는 방식이 아니라, UI 패턴과 배치 자체가 팝업의 목적을 반영해야 합니다.

| # | 팝업 이름 | 레이아웃 구조 | UI 패턴 | 디자인 스타일 |
|---|---|---|---|---|
| 1 | 스크롤 인터랙션 팝업 | **우하단 플로팅 카드** | 오버레이 없음, 스크롤 트리거, 슬라이드업 | Glassmorphism |
| 2 | 인터랙티브 플랜 비교 팝업 | **중앙 모달 + 플랜 카드 그리드** | 카드 선택 UI, 토글 전환, CTA 강조 | Interactive |
| 3 | 관리자 연동 공지 팝업 | **화면 상단 슬라이드다운 띠** | 풀 위드 배너, 페이지 콘텐츠 위 고정 | Editorial |
| 4 | 쿠폰 다운로드 팝업 | **티켓 UI (tear-off 구조)** | 좌: 혜택, 우: 점선+코드 절취 구조 | Brutalism |
| 5 | 영상 모달 팝업 | **다크 풀스크린 오버레이 + iframe** | 텍스트 최소화, 영상 주인공, X 버튼만 | Spatial UI |
| 6 | 플로팅 토스트 팝업 | **우하단 토스트 스택** | 작은 카드(300px) 자동 순환, 스택 쌓임 | Minimal |
| 7 | 오늘 하루 보지 않기 팝업 | **풀이미지 전면 모달** | 이미지 전체, Bento 패널 하단 고정 | Bento Grid |
| 8 | 탭형 이벤트 팝업 | **중앙 모달 + 상단 탭 네비** | 탭 전환 UI, 각 탭별 다른 콘텐츠 | Corporate |
| 9 | 로그인/회원 유도 팝업 | **좌우 분할 모달** | 좌: 브랜드, 우: 소셜 로그인 + 입력 폼 | Neumorphism |
| 10 | 실시간 관리자 메시지 팝업 | **화면 상단 긴급 알림 띠** | 풀 위드 시스템 배너, 긴급도 표시 | AI Native (Dark) |

# 디자인 방향성

## 핵심 목표

### 1. 디자인 스타일 다변화

라운드형 Tailwind 스타일의 획일화에서 벗어나 각 팝업 목적에 맞는 **트렌디한 디자인 시스템**을 적용합니다.

| 스타일 | 핵심 특성 | 적용 팝업 |
|---|---|---|
| **Glassmorphism** | 반투명 블러, 유리 질감, 빛 산란 | #1 스크롤 인터랙션 |
| **Interactive** | 직관적 인터랙션, 명확한 정보 전달, 반응형 탐색 | #2 인터랙티브 플랜 비교 |
| **Editorial** | 굵은 타이포, 강한 색 대비, 텍스트 주인공 | #3 관리자 공지 |
| **Brutalism** | 두꺼운 테두리, offset shadow, 강한 임팩트 | #4 쿠폰 다운로드 |
| **Spatial UI** | 3D 레이어드 깊이감, 다크 공간감 | #5 영상 모달 |
| **Minimal** | 불필요 요소 제거, 순백/순흑, 여백 중심 | #6 플로팅 토스트 |
| **Bento Grid** | 정보 블록 분할, 그리드 구조화 | #7 오늘 하루 숨김 |
| **Corporate** | 정형 구조, 브랜드 신뢰성, 명확한 계층 | #8 탭형 이벤트 |
| **Neumorphism** | 볼록/오목 소프트 3D, 촉감형 버튼 | #9 로그인/회원 유도 |
| **AI Native (Dark)** | 다크 글로우, 스캔 라인, 긴급 시스템 UI | #10 실시간 관리자 메시지 |

# 1. 스크롤 인터랙션 팝업

## 디자인 컨셉

### "Floating Motion" — Glassmorphism

**대표 사례:** Linear

반투명 유리 질감의 플로팅 카드. 빛 굴절과 백드롭 블러가 겹쳐 공간감을 만드는 트렌디한 UI.
배경 콘텐츠가 카드 뒤로 흐릿하게 비쳐 팝업이 페이지 위에 자연스럽게 부유하는 느낌을 줍니다.

## 포인트 컬러

| 역할 | 색상명 | HEX |
|---|---|---|
| Primary (Glow Accent) | 인디고 바이올렛 | `#818CF8` |
| Background (Frosted) | 반투명 아이보리 | `#EEF2FF` + `rgba(255,255,255,0.15)` |

- `backdrop-filter: blur(16px)` 필수 적용
- border: `1px solid rgba(255, 255, 255, 0.3)` — 글래스 엣지 표현
- box-shadow: `0 8px 32px rgba(129, 140, 248, 0.2)` — 컬러 글로우

## 주요 기능

* 스크롤 위치 트리거 (30% 스크롤 시 등장)
* Fade + Slide 애니메이션
* 모바일 최적화
* 섹션별 노출 설정

## 인터랙션

| 단계 | 트리거 | 동작 |
|---|---|---|
| 등장 | 스크롤 30% 도달 | `translateY(40px) → 0` + `opacity 0 → 1`, 0.5s ease-out |
| 호버 | 마우스 오버 | 카드 `translateY(-4px)` + 글로우 box-shadow 확장 |
| 닫기 | X 버튼 클릭 | `translateY(40px) + opacity 0` 역방향 슬라이드다운, 0.3s |
| 재등장 방지 | 닫기 후 | sessionStorage 저장, 세션 내 1회만 노출 |

## 강점

* 인터랙션 퀄리티 강조 가능
* 랜딩페이지 완성도 상승
* 브랜드 감도 표현에 유리

## 분위기

트렌디 / 감성형 / 인터랙션 중심

# 2. 인터랙티브 플랜 비교 팝업

## 디자인 컨셉

### "Plan Showcase" — Interactive

**대표 사례:** Stripe

Stripe에서 영감을 받은 인터랙티브 플랜 비교 UI. 사용자가 카드를 직접 선택하고 토글로 옵션을 전환하며 탐색하는 능동적 경험.
화려한 애니메이션보다 명확한 정보 전달과 자연스러운 상호작용에 집중합니다.

## 포인트 컬러

| 역할 | 색상명 | HEX |
|---|---|---|
| Primary (Stripe Purple) | 스트라이프 퍼플 | `#635BFF` |
| Background (Clean White) | 클린 화이트 | `#FFFFFF` |

- 선택된 카드: `border: 2px solid #635BFF` + `box-shadow: 0 0 0 4px rgba(99,91,255,0.15)`
- 추천 배지: `background: #635BFF`, `color: #fff`, `font-weight: 700`
- 토글 활성: `background: #635BFF`

## 주요 기능

* 플랜 카드 선택 하이라이트 (Popup API GET)
* 월간/연간 토글 전환
* 추천 플랜 배지 표시
* CTA 버튼 강조 (외부 링크)

## 인터랙션

| 단계 | 트리거 | 동작 |
|---|---|---|
| 등장 | 버튼 클릭 / 자동 | `scale(0.96) → 1` + `opacity 0 → 1`, 0.4s ease-out |
| 카드 호버 | 마우스 오버 | `translateY(-4px)` + border-color + shadow 부드럽게 전환, 0.2s |
| 카드 선택 | 클릭 | 선택 카드 퍼플 테두리 + glow, 비선택 카드 opacity 0.6 |
| 토글 전환 | 월간↔연간 클릭 | 가격 숫자 `fadeOut → fadeIn` 0.2s + 토글 슬라이드 |
| CTA 버튼 | 호버 | 배경 `#635BFF` 진하게 + `translateY(-1px)` |
| 닫기 | X 또는 오버레이 클릭 | `scale(0.95) + opacity 0`, 0.25s |

## 강점

* 서비스 플랜 전환율 향상
* 직관적 비교 UX
* 폼 제출 없이 Popup API GET만으로 운영 가능

## 분위기

SaaS / 서비스형 / 정보 탐색형

# 3. 관리자 연동 공지 팝업

## 디자인 컨셉

### "Clean Notice" — Editorial

**대표 사례:** Aesop

신문·잡지 헤드라인처럼 텍스트가 주인공인 전면 배너 UI.
이미지 없이 굵은 타이포그래피와 강한 색 대비만으로 시선을 집중시킵니다.
풀와이드 띠 배너로 상단 고정되며 콘텐츠를 밀어내지 않고 오버레이됩니다.

## 포인트 컬러

| 역할 | 색상명 | HEX |
|---|---|---|
| Primary (Punch Orange) | 에디토리얼 오렌지 | `#F97316` |
| Background (Off-White) | 크림 화이트 | `#FAFAFA` |

- 타이포: `font-weight: 800`, `letter-spacing: -0.02em`
- 왼쪽 강조 바: `4px solid #F97316`
- 다크 모드 변형: `#1C1917` 배경 + `#F97316` 텍스트

## 주요 기능

* 관리자 실시간 수정 (Popup API GET)
* 예약 발행 / 자동 종료
* 페이지별 노출 설정
* 오늘 하루 보지 않기 (쿠키 처리)

## 인터랙션

| 단계 | 트리거 | 동작 |
|---|---|---|
| 등장 | 페이지 로드 | 상단에서 `translateY(-100%) → 0`, 0.4s spring ease |
| 텍스트 | 등장 후 | 제목 → 설명 → 버튼 stagger fade-in, 각 0.1s 딜레이 |
| CTA 버튼 | 호버 | 배경색 반전 (오렌지 배경 + 흰 텍스트) |
| 닫기 | X 클릭 | `translateY(-100%)` 슬라이드업, 0.25s |
| 재노출 방지 | "오늘 하루" 체크 | 자정 만료 Cookie 저장 |

## 강점

* 운영 효율 극대화
* 유지보수 비용 절감
* 공지 운영 편의성 향상

## 분위기

기업형 / 안정적 / 운영 중심

# 4. 쿠폰 다운로드 팝업

## 디자인 컨셉

### "Conversion Boost" — Brutalism

두꺼운 테두리, 강한 색 대비, 납작한 offset shadow가 특징인 브루탈리즘 UI.
쿠폰 티켓의 tear-off(점선 절취) 구조와 결합해 시각적 임팩트와 전환율을 극대화합니다.

## 포인트 컬러

| 역할 | 색상명 | HEX |
|---|---|---|
| Primary (Punch Yellow) | 임팩트 옐로우 | `#FACC15` |
| Background (Zinc Dark) | 딥 블랙 | `#18181B` |

- border: `3px solid #18181B`
- box-shadow: `6px 6px 0 #18181B` — 브루탈 offset 그림자
- 버튼: 배경 `#FACC15`, 텍스트 `#18181B`, `font-weight: 900`
- 점선 구분선: `border-left: 2px dashed #18181B`

## 주요 기능

* 쿠폰 코드 복사 (Clipboard API)
* 이메일 수집 (Edit API POST)
* 회원 연동
* CTA 강조 구조
