9개 컬럼 타입(상세 설명)
각 타입에는 공통 옵션: label(라벨), name(식별자), required(필수 여부), placeholder, helpText, defaultValue 등을 설정할 수 있습니다.
선택형(single/multi/checkbox)은 options 배열(예: {value:"A", label:"옵션 A"})을 가집니다.

text

한 줄 입력용 텍스트 필드(이름, 제목 등).

옵션: maxLength, pattern(정규식 검증).

multi_text

여러 줄 텍스트(설명, 문의 내용, 자기소개 등).

옵션: rows, maxLength.

number

숫자 전용 입력(수량, 가격 등).

옵션: min, max, step.

calendar

날짜/시간 선택기(단순 날짜 또는 날짜+시간).

옵션: dateOnly / dateTime, minDate, maxDate.

file

파일 업로드(이미지, PDF 등).

옵션: accept(허용 확장자), maxSizeMB, multiple(다중 업로드 허용).

single_select

드롭다운 또는 라디오 형태의 단일 선택(예: 지역, 카테고리).

옵션: options, placeholder.

multi_select

다중 선택(태그, 관심사 등).

옵션: options, maxSelections.

checkbox

단일/복수 체크 박스(동의 체크, 옵션 선택).

옵션: options(하나만 있으면 동의 체크로 사용).

email

이메일 형식 전용 필드(자동 검증).

옵션: verify(확인 입력 필드 추가 가능).

제한 & 권장사항(중요)
컬럼 수 제한: 폼당 최대 10개 컬럼. 꼭 필요한 항목만 설계하세요.

타입 변경 시 주의: 운영 중인 폼의 컬럼 타입을 변경하면 기존 저장 데이터와 호환성 문제가 생길 수 있습니다. (예: file → text) 변경 데이터 소실

파일 업로드 주의: 파일 저장 용량 및 보안(확장자 제한, 바이러스 검사) 정책을 확인하세요.

개인정보: 주민등록번호 같은 민감정보는 수집 금지 또는 암호화 저장/관리 필요. 개인정보 수집 시 별도 동의 필드(checkbox)를 의무화하세요.
