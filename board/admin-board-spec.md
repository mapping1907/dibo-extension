# 관리자 게시판 관리 명세서

> 대상: 관리자 페이지 개발자  
> 게시글 관리와 댓글 관리는 **별도 페이지**로 구성합니다.

---

## 1. 전체 구조

```
관리자 > 게시판
├── 게시글 관리   (/admin/boards)
└── 댓글 관리     (/admin/comments)
```

---

## 2. 게시글 관리 페이지 (`/admin/boards`)

### 2-1. 개요

하나의 홈페이지에 **여러 게시판**이 존재합니다.  
예시: 공지, 커뮤니티, 문의, 이벤트 등

관리자는 게시판 단위로 게시글을 선택하고, 해당 게시판의 게시글 목록을 리스트로 관리합니다.

---

### 2-2. 레이아웃 구성

```
[게시판 선택 드롭다운 또는 탭]
공지 | 커뮤니티 | 문의 | 이벤트 | ...

[검색 + 필터 영역]
검색어 입력 / 카테고리 필터 / 공개·비공개 필터 / 기간 필터

[게시글 테이블]
번호 | 게시판 | 카테고리 | 제목 | 작성자 | 좋아요 | 조회수 | 작성일 | 상태 | 관리

[페이지네이션]
```

---

### 2-3. 게시글 테이블 컬럼

| 컬럼 | 설명 |
|---|---|
| 번호 | 게시글 ID 또는 순번 |
| 게시판 | 게시판 이름 (board_id → 표시명) |
| 카테고리 | 게시글 카테고리 |
| 제목 | 클릭 시 상세 보기 or 새 탭 이동 |
| 작성자 | 회원 표시명 + 회원 ID |
| 좋아요 | 좋아요 수 |
| 조회수 | 조회수 |
| 작성일 | `YYYY-MM-DD` |
| 상태 | 공개 / 비공개 (토글 가능) |
| 관리 | 수정 / 삭제 버튼 |

---

### 2-4. 관리 기능

| 기능 | 설명 |
|---|---|
| 공개/비공개 전환 | 게시글 행에서 즉시 토글 (`is_public`) |
| 고정/고정 해제 | 목록 상단 고정 (`pinned`) |
| 게시글 수정 | 관리자 편집 화면으로 이동 |
| 게시글 삭제 | 확인 모달 후 삭제 |
| 일괄 삭제 | 체크박스 선택 후 일괄 삭제 |

---

### 2-5. API 연동

| Method | Endpoint | 설명 |
|---|---|---|
| GET | `/admin/boards` | 전체 게시판 목록 |
| GET | `/admin/boards/{board_id}/posts` | 게시판별 게시글 목록 (검색, 필터, 페이지) |
| PATCH | `/admin/posts/{id}` | 단일 필드 수정 (is_public, pinned 등) |
| DELETE | `/admin/posts/{id}` | 게시글 삭제 |
| DELETE | `/admin/posts` | 일괄 삭제 (body: `{ ids: [1, 2, 3] }`) |

---

## 3. 댓글 관리 페이지 (`/admin/comments`)

### 3-1. 개요

**모든 게시판의 댓글을 하나의 페이지**에서 관리합니다.  
상단 탭으로 범위를 좁혀 볼 수 있습니다.

---

### 3-2. 상단 탭 메뉴

```
[전체] [공지] [커뮤니티] [문의] [이벤트] ... [신고된 댓글]
```

- **전체**: 모든 게시판의 댓글
- **게시판별 탭**: 해당 게시판에 달린 댓글만 표시
- **신고된 댓글**: `report_count > 0`인 댓글만 필터링
- 탭 클릭 시 페이지 1로 초기화

---

### 3-3. 상단 정렬 옵션 (탭 아래)

```
[인기댓글순] [최신순] [연동된 게시글순]
```

| 정렬 | 기준 |
|---|---|
| 인기댓글순 | `likes` 내림차순 |
| 최신순 | `date` 내림차순 |
| 연동된 게시글순 | `post_id` 기준 그룹핑 후 최신 게시글 우선 |

---

### 3-4. 댓글 목록 구성

각 댓글 항목의 표시 구조:

```
[작성자명]  [원 게시글 제목 — 클릭 시 해당 게시글로 이동]   [작성일]  [신고 수]  [상태]
댓글 내용 (비밀댓글이면 🔒 비밀글입니다. 로 표시, 관리자는 내용 열람 가능)
[이미지 썸네일 목록 (있는 경우)]
                                              [숨김 처리] [삭제]
```

---

### 3-5. 댓글 아이템 컬럼

| 항목 | 설명 |
|---|---|
| 작성자 | 표시명 (회원 ID 툴팁 또는 괄호 표시 권장) |
| 원 게시글 제목 | 작성자 옆에 표시, 클릭 시 해당 게시글 이동 |
| 댓글 내용 | 비밀댓글은 관리자에게 항상 원문 표시 |
| 첨부 이미지 | 있는 경우 썸네일 표시 |
| 작성일 | `YYYY-MM-DD` |
| 신고 수 | `report_count` 표시, 0이면 미표시 or 회색 |
| 상태 배지 | 공개 / 비밀글 / 숨김 처리됨 |

---

### 3-6. 관리 기능

| 기능 | 설명 |
|---|---|
| 숨김 처리 | `is_hidden: true` — 사용자에게 안 보이고 관리자는 열람 가능 |
| 숨김 해제 | `is_hidden: false`로 복구 |
| 댓글 삭제 | 완전 삭제 (복구 불가 — 확인 모달 필요) |
| 비밀댓글 열람 | 관리자는 `secret: true` 댓글도 원문 표시 |
| 신고 내역 확인 | 신고 수 클릭 시 신고자 목록 모달 (선택 사항) |
| 일괄 삭제 | 체크박스 선택 후 일괄 처리 |

---

### 3-7. 신고된 댓글 탭

- `report_count >= 1`인 댓글만 별도 필터링
- 신고 수 기준으로 내림차순 기본 정렬
- 신고 수가 일정 수치 이상이면 자동 숨김 처리하는 정책 적용 가능 (임계값은 운영 정책으로 결정)

---

### 3-8. 대댓글 처리

- 대댓글도 댓글 목록 내 하위 항목으로 표시하거나 별도 탭으로 분리 가능
- 최소 요건: 댓글 항목 내에서 대댓글 펼쳐보기 + 삭제/숨김 기능 제공

---

### 3-9. API 연동

| Method | Endpoint | 설명 |
|---|---|---|
| GET | `/admin/comments` | 전체 댓글 목록 (탭/정렬/페이지 쿼리 지원) |
| GET | `/admin/comments?board_id={id}` | 게시판별 필터 |
| GET | `/admin/comments?reported=true` | 신고된 댓글만 |
| PATCH | `/admin/comments/{id}` | 숨김 처리 (`is_hidden`) |
| DELETE | `/admin/comments/{id}` | 댓글 삭제 |
| DELETE | `/admin/comments` | 일괄 삭제 (body: `{ ids: [...] }`) |
| PATCH | `/admin/replies/{id}` | 대댓글 숨김 처리 |
| DELETE | `/admin/replies/{id}` | 대댓글 삭제 |

**댓글 목록 쿼리 파라미터**

```
GET /admin/comments?board_id=notice&sort=latest&reported=true&page=1&limit=20
```

| 파라미터 | 설명 |
|---|---|
| `board_id` | 게시판 필터 (없으면 전체) |
| `sort` | `popular` \| `latest` \| `by_post` |
| `reported` | `true` 이면 신고 댓글만 |
| `page` | 페이지 번호 |
| `limit` | 페이지당 댓글 수 (기본 20) |

---

## 4. 정리: 사이트 vs 관리자 권한 비교

| 기능 | 일반 사용자 | 관리자 |
|---|---|---|
| 게시글 작성 | 본인만 | 모든 게시판 |
| 게시글 수정/삭제 | 본인 게시글만 | 전체 |
| 댓글 삭제 | 본인 댓글만 | 전체 |
| 비밀댓글 열람 | 본인 작성 댓글만 | 전체 |
| 댓글 고정 | 불가 | 가능 |
| 댓글 숨김 | 불가 | 가능 |
| 게시글 공개/비공개 | 불가 | 가능 |
| 게시글 고정 | 불가 | 가능 |
| 신고 내역 확인 | 불가 | 가능 |
