다음과 같은 내용을 참고해서 순차적으로 코드를 추가 및 수정 해줘

##다음##
1. axios와 token값은 이미 헤더에 저장되어있어
- 별도로 추가안해도 돼

2. 지금 코드 콘텐츠 구성은
- 데이터를 변수에 담아 로컬에서 데이터를 제공중이야
- api에서 데이터를 패치하지 않으면 로컬 데이터를 사용, api 패치되면 api 데이터를 사용해줘

3. 현재 코드 콘텐츠의 제목, 설명, 키워드를 추천해줘
- 사용자의 언어(코드를 모르는 사용자)로 알기 쉽게해줘
- 사용해보고 싶게 해줘
- 구글 검색노출에 용이하게 해줘
- 코드 말고 채팅창에 추천해줘

3. 연동할 api는 다음과 같아
<script>
    /**
     * 타이머 API 연동 가이드
     *

     * 주요 필드 설명:

     * - end_title: 타이머 종료 시 표시할 제목
     * - created_at: 데이터 생성 시각

     * 활용 예시:
     * - 이벤트 시작/종료 카운트다운 UI 구성

     * - 서비스 오픈/마감 안내 알림
     */
