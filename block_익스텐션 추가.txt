##다음##
1. axios와 token값은 이미 헤더에 저장되어있어
- 별도로 추가안해도 돼

2. 지금 코드 콘텐츠 구성은
- 데이터를 변수에 담아 로컬에서 데이터를 제공중이야
- api에서 데이터를 패치하지 않으면 로컬 데이터를 사용, api 패치되면 api 데이터를 사용해줘

3. 현재 코드 콘텐츠의 제목, 설명, 키워드를 추천해줘
- 사용자의 언어(코드를 모르는 사용자)로 알기 쉽게해줘
- 사용해보고 싶게 해줘
- 구글 검색노출에 용이하게 해줘
- 코드말고 채팅창에 추천해줘

     * - created_at: 데이터 생성 시각 (ISO 8601 형식)
     * - updated_at: 데이터 최종 수정 시각 (ISO 8601 형식)
